
# Securing AI — Course Roadmap

## Course Overview

The Securing AI certification course consists of seven instructional modules designed to introduce learners to security challenges throughout the artificial intelligence lifecycle.

The course progresses from fundamental concepts and threat modeling to practical attacks, secure deployment, and operational defense.

Students are encouraged to complete the modules in order.

---

## Module 1 — Introduction to AI Security

**Focus:** Understanding AI security fundamentals and common security risks.

### Topics

- Artificial intelligence and machine learning fundamentals.
- Why AI systems require specialized security protections.
- AI security risks and attack surfaces.
- Adversarial examples and data poisoning.
- Prompt injection and model information leakage.
- Real-world AI failures and security incidents.
- AI applications in cybersecurity.

### Learning Outcomes

Students will develop a foundational understanding of AI security, identify common threats, and explain how AI system vulnerabilities differ from traditional software security risks.

[Start Module 1](Module_1_Introduction/README.md)

---

## Module 2 — Threat Modeling AI Systems

**Focus:** Identifying, analyzing, and prioritizing AI security threats.

### Topics

- AI assets and attack surfaces.
- Trust boundaries.
- STRIDE threat modeling.
- DREAD risk prioritization.
- Failure Modes and Effects Analysis (FMEA).
- Security risk assessment.
- Defensive control selection.

### Learning Outcomes

Students will learn to examine an AI system, identify potential security weaknesses, evaluate risk, and recommend appropriate controls.

[Start Module 2](Module_2_Threat_Modeling/README.md)

---

## Module 3 — Supply Chain and Data-Level Attacks

**Focus:** Understanding threats targeting AI training data and supporting dependencies.

### Topics

- AI supply chain security.
- Data poisoning.
- Label-flipping attacks.
- Clean-label poisoning.
- Data injection and duplication.
- Data drift and distribution manipulation.
- Suspicious data detection.
- Defensive data cleaning and anomaly detection.

### Learning Outcomes

Students will investigate how manipulated training data can affect machine learning models and evaluate methods for detecting or reducing data-level attacks.

[Start Module 3](Module_3_Data_Level_Attacks/README.md)

---

## Module 4 — Model Exploitation Techniques

**Focus:** Understanding attacks against trained machine learning models.

### Topics

- White-box, gray-box, and black-box attacks.
- Adversarial evasion.
- Fast Gradient Sign Method (FGSM).
- Projected Gradient Descent (PGD).
- Model extraction.
- Membership inference.
- Model inversion.
- Transfer attacks and surrogate models.
- Model backdoors.
- API-based exploitation.
- Attack chains.

### Learning Outcomes

Students will investigate how trained models can be manipulated or exploited and examine defenses related to model robustness, privacy, and security.

[Start Module 4](Module_4_Model_Exploitation/README.md)

---

## Module 5 — LLM Security and Prompt Injection

**Focus:** Securing large language models and applications built around them.

### Topics

- LLM attack surfaces.
- Direct and indirect prompt injection.
- Jailbreaking.
- Prompt leakage.
- Sensitive information disclosure.
- Retrieval-Augmented Generation (RAG) security.
- Knowledge poisoning.
- Agent and tool exploitation.
- Defensive application architecture.
- LLM security testing.

### Learning Outcomes

Students will examine security vulnerabilities in LLM-powered applications and evaluate defensive controls using controlled simulations, including the SecureAssist learning environment.

[Start Module 5](Module_5_LLM_Security/README.md)

---

## Module 6 — Secure Deployment and Infrastructure

**Focus:** Protecting the systems and infrastructure supporting deployed AI applications.

### Topics

- AI deployment architectures.
- API and inference endpoint security.
- Authentication and authorization.
- Identity and access management.
- Least privilege.
- Secrets management.
- Container and runtime security.
- Network segmentation.
- Model integrity.
- Secure deployment pipelines.
- Logging and monitoring.

### Learning Outcomes

Students will evaluate infrastructure security weaknesses and explore defensive controls using the SentinelAI simulated deployment environment.

[Start Module 6](Module_6_Secure_Deployment/README.md)

---

## Module 7 — AI Security Operations and Defense

**Focus:** Detecting, investigating, containing, and recovering from AI security incidents.

### Topics

- AI security operations.
- Asset inventories and security baselines.
- Logging and telemetry.
- AI-specific attack detection.
- Detection engineering.
- Incident response.
- Containment and recovery.
- Model rollback and integrity verification.
- AI red teaming.
- Security metrics.
- Operational readiness.

### Final Capstone — Defend an AI System

Students will investigate a simulated AI security incident by analyzing telemetry, identifying suspicious activity, evaluating potential compromise, applying containment, restoring trusted operation, and documenting their findings.

### Learning Outcomes

Students will connect concepts from the previous modules to understand how AI systems can be protected throughout their operational lifecycle.

[Start Module 7](Module_7_AI_Defense/README.md)
