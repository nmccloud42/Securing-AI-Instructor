
# Module 2 — Threat Modeling AI Systems

[Course Home](../README.md) | [Getting Started](../GETTING_STARTED.md) | [Course Roadmap](../COURSE_ROADMAP.md)

## Module Overview

This module covers AI assets, trust boundaries, STRIDE, DREAD, FMEA, threat assessment, and defensive controls. Students read the instructional content, work through the provided notebook activities, and submit completed work for instructor review.

**Learning goal:** Identify threats, prioritize risk, and recommend security controls for an AI system.

## Before You Begin — Cyber Range Setup

1. Access your **designated cyber range machine**.
2. If you need help, open the **Getting Started HTML guide on the desktop**.
3. Double-click the **course shortcut on the desktop** to open the course in **VS Code**.
4. In VS Code Explorer, open this module folder.
5. Locate `Module2_Student.ipynb`.

## Make Your Own Copy (Required)

**Do not edit `Module2_Student.ipynb` directly.**

1. Right-click `Module2_Student.ipynb` in VS Code Explorer and select **Copy**.
2. Paste it into your **instructor-designated personal working folder**.
3. Rename your copy to `Module2_Student_FirstName_LastName.ipynb`.
4. Open **your copy** in VS Code and complete all activities there.

If you do not know where to save personal work, ask the instructor before proceeding.

1. Read the instructional text and task directions.
2. Run the setup and demonstration cells using the course-provided Python kernel.
