
# Securing AI — Instructor Resources (Private Repository)

This content is intended for the **private `Securing-AI-Instructor` repository**, not the public student repository.

## Course Delivery

Students use assigned cyber range machines. Each desktop includes a course shortcut that opens the student materials in VS Code and a Getting Started HTML guide. Students make their own copies of `ModuleX_Student.ipynb`, complete assignments in VS Code, and submit their completed `.ipynb` files to the instructor.

## Instructor Workflow

1. Verify that the cyber range desktop shortcuts open the intended course workspace and Getting Started HTML guide.
2. Confirm that students have an **approved personal work location** that persists as needed.
3. Confirm that the course-provided Python kernel and notebook dependencies are available.
4. Specify the submission destination, deadlines, and any permitted collaboration.
5. Review submitted student notebooks using the matching private `ModuleX_Instructor.ipynb` reference notebook.
6. Provide feedback and record grades in the approved institutional system.

## Keep Private

Do not publish instructor notebooks, answer keys, reference solutions, private student submissions, or student information in the public course repository.
