
# Securing AI — AI System Security Certification Course

Welcome to **Securing AI**, a hands-on educational course focused on understanding, evaluating, and defending artificial intelligence (AI) and machine learning (ML) systems.

This course introduces security challenges across the AI lifecycle, including training data, model behavior, large language model applications, deployment infrastructure, and operational defense.

Students will learn through instructional readings, interactive Python demonstrations, guided security exercises, written analysis, and instructor-reviewed practical assessments.

**No previous AI security experience is required.**

## How the Course Works

Each module contains a student notebook designed to introduce important AI security concepts and provide opportunities to apply them.

### 1. Learn

Read the instructional material to understand the security concepts, attack methods, and defensive techniques covered in the module.

### 2. Observe

Run the provided Python demonstrations and examine the generated outputs, graphs, and model predictions.

### 3. Practice

Complete the assigned coding tasks, experiments, and written-response questions.

Follow the instructions in the notebook and document your observations.

### 4. Analyze

Interpret your experimental results and explain how they relate to AI security.

### 5. Submit

Complete the end-of-module assessment, save your work, and submit your completed notebook according to the instructor's directions.

---

## Learning Objectives

By the end of the course, students should be able to:

1. Explain fundamental AI and machine learning security concepts.
2. Identify AI assets, attack surfaces, and trust boundaries.
3. Apply structured threat modeling and risk assessment.
4. Investigate data poisoning and supply chain vulnerabilities.
5. Demonstrate representative model exploitation techniques.
6. Identify vulnerabilities in LLM-powered applications.
7. Evaluate security controls for AI deployment environments.
8. Analyze AI security telemetry and investigate simulated incidents.
9. Recommend defensive controls and recovery strategies.
10. Explain the importance of security throughout the AI lifecycle.

## Responsible Use

All attacks and security experiments in this course are intended for authorized educational and research environments only.

Use the supplied datasets, simulations, and instructional resources. Do not conduct unauthorized testing against real systems, applications, APIs, or infrastructure.
