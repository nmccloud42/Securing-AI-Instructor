
# Securing AI — AI System Security Certification Course

Welcome to **Securing AI**, a seven-module, hands-on course covering the security of artificial intelligence and machine learning systems.

**This course is completed inside your assigned cyber range machine using Visual Studio Code (VS Code).** Your cyber range desktop includes a shortcut that opens the course in VS Code and a separate **Getting Started** HTML guide for quick reference.

## Start Here

### [Getting Started — Read This First](GETTING_STARTED.md)

1. Sign in to your designated cyber range machine using the access instructions provided by your instructor.
2. On the desktop, open the **Getting Started** HTML guide if you need directions.
3. Double-click the **course shortcut** on the desktop to open the course in VS Code.
4. Find the module you are assigned and **make a personal copy of its student `.ipynb` notebook before editing**.
5. Complete your copy in VS Code, save it, and submit the completed `.ipynb` file to your instructor using the designated submission method.

**Do not edit the original course notebook.** Your instructor may update the course files, and edits to the shared originals may be overwritten or affect other learners.

## How Learning Works

Each module includes instructional material, guided demonstrations, student exercises, written analysis, and instructor-reviewed assessments. Read the instructions, run the relevant notebook cells, complete assigned work in your personal copy, and submit that copy for review.

## Responsible Use

Security experiments must remain within the authorized course and cyber range environments. Do not test systems outside your assigned scope. Never include passwords, tokens, or other secrets in submitted notebooks.
